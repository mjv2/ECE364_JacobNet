# ECE364_JacobNet
Working repository for ECE 364 final project option #3, a neural network designed to make bids in the NYISO energy market.

The model is a fully-connected Feed Forward Neural Network, trained on 2015 Real Time and Day Ahead zone-hour energy prices for the New York Independent System Operator electricity market, and evaluated by generating bid signals based on 2016 data.

Current Model Size: 6,674,469 parameters (11 layers)
