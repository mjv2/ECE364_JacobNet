# ECE364_JacobNet
Working repository for ECE 364 Final Project Option #3, a machine learning model tasked with making bids in the NYISO energy market.

The model is a fully-connected Feed Forward Neural Network with 11 layers and 6,674,469 parameters, trained on 2015 Real Time and Day Ahead zone-hour energy prices for the New York Independent System Operator electricity market, and evaluated by generating bid signals based on 2016 data.
